# 2D Brainfuck - Двумерный язык программирования

Этот язык является расширением Brainfuck с двумерным массивом ячеек 1000×1000 и новыми командами для навигации.

## Команды языка

### Работа со значениями

| Команда | Описание |
|---------|----------|
| `^_^` | Увеличить значение в текущей ячейке на 1 (по модулю 256) |
| `!_!` | Уменьшить значение в текущей ячейке на 1 (по модулю 256) |
| `*_*` | Вывести символ из текущей ячейки (ASCII) |
| `?_?` | Прочитать символ из ввода и записать его код в текущую ячейку |

### Перемещение по сетке

| Команда | Описание |
|---------|----------|
| `D_D` | Переместить курсор ВПРАВО (col + 1) |
| `A_A` | Переместить курсор ВЛЕВО (col - 1) |
| `S_S` | Переместить курсор ВНИЗ (row + 1) |
| `W_W` | Переместить курсор ВВЕРХ (row - 1) |

### Копирование значений

| Команда | Описание |
|---------|----------|
| `>_>` | Скопировать значение из текущей ячейки в правую соседнюю ячейку |
| `<_<` | Скопировать значение из текущей ячейки в левую соседнюю ячейку |

### Управление потоком выполнения (циклы)

| Команда | Описание |
|---------|----------|
| `(-:` | Начало цикла. Если значение текущей ячейки = 0, перепрыгивает на соответствующую `:-)` |
| `:-)` | Конец цикла. Если значение текущей ячейки ≠ 0, возвращается на соответствующую `(-:` |

## Ввод данных

Для ввода символов используется команда `?_?`. Символы передаются в параметре `inputt` функции `run_code`.

### Примеры ввода:

```python
# Ввод одного символа 'A'
result = run_code('?_? *_*', 'A_A')  # Выведет 'A' (код 65)

# Ввод с последующим изменением
result = run_code('?_? ^_^ *_*', 'A_A')  # Выведет 'B' (код 66)

# Ввод нескольких символов
result = run_code('?_? *_* ?_? *_*', 'A_A B_B')  # Выведет 'AB'

# Ввод с перемещением
result = run_code('?_? D_D ?_? A_A *_*', 'A_A B_B')  # Выведет 'B'
